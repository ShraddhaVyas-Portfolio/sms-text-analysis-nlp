SMS Text Analysis Using Natural Language Processing
Overview
This project applies Natural Language Processing (NLP) techniques to analyze a dataset of SMS messages.

The analysis explores communication patterns, word frequency, sentiment distribution, and messaging trends using Python.

Dataset
National University of Singapore SMS Corpus

Records: 48,598 SMS Messages

Features:

Message
Length
Country
Date

Text Preprocessing
Word Frequency Analysis
Sentiment Analysis
Data Visualization
